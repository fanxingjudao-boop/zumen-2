レビュー観点

このモックは、操作性と視認性の確認を主目的としています。

  • 主要導線（検索 → 結果 → 詳細 → 閲覧）を最小操作で遷移できるか
  • 文字コントラスト・サイズが現場利用（屋外/手袋操作想定）に耐えるか
  • 状態表示（接続可否、ヒットページ、キャッシュ情報）が即時に読めるか
  • タップ対象（チップ/ボタン）のサイズが十分か
