# PWA UI仕様書（スマホ閲覧専用）

## 1. 目的
現場利用者がスマホで、オフライン環境下でも図面を検索・閲覧できること。更新・登録・編集は行わない（閲覧専用）。

## 2. 対象環境
- iOS Safari / Android Chrome
- 縦持ち基本（閲覧時のみ横持ち推奨）
- 現場ローカルWi-Fi（箱）へ接続。インターネット不要。

## 3. UX原則
1) 操作は3タップ以内で目的の図面に到達  
2) 主導線は「検索→結果→閲覧」  
3) フィルタは最大3つ（facility/area/year）  
4) 端末保存は「お気に入り・履歴」中心（PDF大量保存は避ける）  
5) 段階表示（結果→サムネ→PDF）

## 4. 画面一覧
- S01: ホーム（検索・最近見た・お気に入り・状態表示）
- S02: 検索結果（リスト＋フィルタ）
- S03: 図面詳細（メタ＋ヒットページ）
- S04: ビューワ（PDF、ズーム/パン、回転）
- S05: 設定/情報（バージョン、キャッシュ、ヘルプ）

## 5. 主要API
- GET /api/v1/version
- GET /api/v1/suggest?q=...
- POST /api/v1/search
- GET /api/v1/slices/{id}
- GET /api/v1/slices/{id}/pdf (Range)
- GET /api/v1/slices/{id}/thumbs/{name}

## 6. オフライン（Service Worker）
- アプリシェルはキャッシュ（オフライン起動可）
- 検索結果JSONは短期キャッシュ（例：24h）
- サムネはLRU（上限件数）
- PDFは原則キャッシュしない（例外：一時保存最大N件）

## 7. 受入基準
- 検索→結果→閲覧の導線が成立
- ヒットページへジャンプできる
- オフラインでもアプリは起動し、履歴・お気に入りは見える

## 8. UIモック
- 実画面イメージ（静的モック）: `cad_offline_viewer_spec/docs/pwa_ui_mock.html`
- 本モックは画面遷移と情報配置の確認用であり、実装時はAPI接続・状態管理・アクセシビリティ要件を別途適用する。

## 9. 操作性・視認性の改善方針
- 主要操作（検索・フィルタ・ページジャンプ）はタップ領域を広くし、片手操作でも押しやすくする。
- 文字サイズとコントラストを確保し、屋外や暗所でも判読性を維持する。
- 接続状態・ヒットページ・キャッシュ状態は画面上で常時把握できる配置とする。
- `pwa_ui_mock.html` では上記方針を反映した画面切替タブと高視認配色を提供する。
