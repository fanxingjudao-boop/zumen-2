# PWA UI仕様書（スマホ閲覧専用）

## 1. 目的
現場利用者がスマホで、オフライン環境下でも図面を検索・閲覧できること。更新・登録・編集は行わない（閲覧専用）。

## 2. 対象環境
- iOS Safari / Android Chrome
- 縦持ち基本（閲覧時のみ横持ち推奨）
- 現場ローカルWi-Fi（箱）へ接続。インターネット不要。

## 3. UX原則
1) 操作は3タップ以内で目的の図面に到達  
2) 主導線は「検索→結果→閲覧」  
3) フィルタは最大3つ（facility/area/year）  
4) 端末保存は「お気に入り・履歴」中心（PDF大量保存は避ける）  
5) 段階表示（結果→サムネ→PDF）

## 4. 画面一覧
- S01: ホーム（検索・最近見た・お気に入り・状態表示）
- S02: 検索結果（リスト＋フィルタ）
- S03: 図面詳細（メタ＋ヒットページ）
- S04: ビューワ（PDF、ズーム/パン、回転）
- S05: 設定/情報（バージョン、キャッシュ、ヘルプ）

## 5. 主要API
- GET /api/v1/version
- GET /api/v1/suggest?q=...
- POST /api/v1/search
- GET /api/v1/slices/{id}
- GET /api/v1/slices/{id}/pdf (Range)
- GET /api/v1/slices/{id}/thumbs/{name}

## 6. オフライン（Service Worker）
- アプリシェルはキャッシュ（オフライン起動可）
- 検索結果JSONは短期キャッシュ（例：24h）
- サムネはLRU（上限件数）
- PDFは原則キャッシュしない（例外：一時保存最大N件）

## 7. 受入基準
- 検索→結果→閲覧の導線が成立
- ヒットページへジャンプできる
- オフラインでもアプリは起動し、履歴・お気に入りは見える
